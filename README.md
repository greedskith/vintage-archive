# Vintage Tube & Retro Archive

Cybernetic CRT video archive dashboard across YouTube, Vimeo, DailyMotion, Bilibili, and Internet Archive with vintage year cutoffs, exact duration filters, and live search quota meters.

### Features
* **5 Archival Engines:** YouTube, Vimeo, DailyMotion, Bilibili, and Internet Archive.
* **Vintage Cutoffs:** Filter media from before 2006 to 2026.
* **Exact Time Window:** Exact duration filtering in minutes.
* **4:3 CRT Monitor:** Scanline video player with phosphor themes (Coral, Cyan, Seafoam).
* **Zero Bloat:** Pure flat DOM, no tracking, strict Chill Design specifications.
